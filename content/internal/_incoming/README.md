Trascina qui i manuali originali (.docx, .xlsx, .pptx, .pdf) delle vostre Extension.

Una GitHub Action li converte automaticamente in Markdown e li pubblica come modulo
formativo interno; l'originale viene poi spostato in `content/internal/_originals/`.

Nota: MarkItDown supporta i formati Office moderni (.docx/.xlsx/.pptx) e PDF.
Se un manuale è in formato legacy (.doc/.xls/.ppt), salvalo prima nel formato
moderno equivalente (Salva con nome) prima di caricarlo qui.
